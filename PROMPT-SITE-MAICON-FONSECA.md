### 4.7 Calculadora de calorias e macros
Título: "QUANTO SEU CORPO GASTA POR DIA?".
- **Campos:** sexo, idade, peso (kg), altura (cm), nível de atividade e objetivo (emagrecer, manter ou ganhar massa).
- **Níveis de atividade e fatores:**
  - Sedentário: 1,2
  - Leve (1 a 3 vezes por semana): 1,375
  - Moderado (3 a 5 vezes): 1,55
  - Intenso (6 a 7 vezes): 1,725
  - Muito intenso: 1,9
- **Cálculos:**
  - IMC = peso ÷ altura². Classificação: abaixo do peso (< 18,5), normal (< 25), sobrepeso (< 30) ou obesidade.
  - Taxa basal (fórmula de Mifflin-St Jeor):
    - Homens: 10 × peso + 6,25 × altura − 5 × idade + 5
    - Mulheres: 10 × peso + 6,25 × altura − 5 × idade − 161
  - Gasto diário = taxa basal × fator de atividade.
  - Meta: emagrecer = gasto − 500; manter = gasto; ganhar massa = gasto + 300.
  - Macros: proteína 2 g/kg, gordura 0,8 g/kg e carboidrato com as calorias restantes. Água: 35 ml/kg.
- **Resultado:** cartões com os números contando até o valor final. Aviso: "Valores aproximados, apenas para referência. Não substituem avaliação profissional."
- **Botão depois do resultado:** "Quero uma estratégia feita para mim". Ele abre o WhatsApp com objetivo, peso, gasto diário e meta de calorias já escritos na mensagem.

### 6.5 Controle dos vídeos da história (`js/story.js`)
```js
const reduce = matchMedia("(prefers-reduced-motion: reduce)").matches;
const saveData = navigator.connection && navigator.connection.saveData;
const isMobile = matchMedia("(max-width: 768px)").matches;

document.querySelectorAll(".chapter").forEach((chapter, i) => {
  const data = CONFIG.story[i];
  const video = chapter.querySelector("video");
  video.muted = true; video.loop = true; video.playsInline = true;
  video.poster = data.poster;
  if (reduce || saveData) return;               // só a capa

  ScrollTrigger.create({
    trigger: chapter,
    start: "top 150%",                           // carrega um pouco antes de aparecer
    onEnter: () => { if (!video.src) video.src = (isMobile && data.mobile) || data.video; },
  });
  ScrollTrigger.create({
    trigger: chapter, start: "top center", end: "bottom center",
    onToggle: (self) => {
      chapter.classList.toggle("is-active", self.isActive);  // dissolve entre vídeos via CSS
      if (self.isActive) video.play().catch(() => {});
      else video.pause();
    },
  });
  // Texto do capítulo: palavras sobem com stagger e o parágrafo aparece depois
  gsap.from(chapter.querySelectorAll(".word__in"), {
    yPercent: 118, stagger: 0.04, duration: 0.9, ease: "power4.out",
    scrollTrigger: { trigger: chapter, start: "top 60%" },
  });
});
```
- Os vídeos ficam numa camada fixa atrás do texto (`position: sticky` ou `pin` do ScrollTrigger). A troca entre capítulos é um `opacity` com transição de 0,8s.
- O marcador "01 / 07" atualiza com o capítulo ativo, e cada número leva ao capítulo com `lenis.scrollTo`.
